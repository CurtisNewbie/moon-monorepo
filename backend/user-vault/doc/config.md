# Configurations

For more configuration, see [github.com/curtisnewbie/miso](https://github.com/CurtisNewbie/miso/blob/main/doc/config.md).

## User Configuration

| property                                      | description                                                                                                                                       | default value |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| user-vault.default-role                       | Default role no for new user                                                                                                                      |               |
| user-vault.notification-count-coalesce-window | Coalescing window for unread notification count changes. A burst of changes for one user within this window is folded into a single announcement. | 1s            |
