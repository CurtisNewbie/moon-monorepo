# Code Review — Frontend

The frontend review contract, named from `frontend/AGENTS.md`.

## Membership

`frontend/AGENTS.md` requires no skill of its own, so the membership is empty: the review runs on the
standards sources below.

## Standards sources

- `frontend/AGENTS.md` — Angular 11 / NgModule, TSLint, test commands, i18n, pagination.
- `frontend/moon/doc/agents/` — `http.md`, `i18n.md`, `pagination.md`, `responsive.md`.
- `frontend/moon/tslint.json` — the lint rules tooling enforces.

## Reviewing a diff

Walk every entry above against the diff, on top of `code-review`'s Standards and Spec axes.
