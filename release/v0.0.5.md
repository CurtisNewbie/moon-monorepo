# v0.0.5

Release notes for the GitHub release body. Cut from `main` after the version bump; see [`README.md`](./README.md).

## Highlights

- **Directory resume cursor** — every directory remembers the file you last read, per user, per directory, and per sort order. Reopening offers "Continue Browsing" and lands on that file, previewed. Comic directories keep their existing behaviour.
- **Durable, queryable cursors** — cursors moved from a Redis hash to `vfm.dir_resume_cursor`, so they survive eviction and restarts. Positions already in Redis are read once and carried into the table.
- **Directory Browse History rebuilt** — one entry per directory and sort, with a sort badge, theme-aware colours, deleted directories filtered out, and resume previewing the recorded file.
- **Custom file ordering** — drag-and-drop reordering in the file list and file tray, stored as a fractional `seq_key`; ascending/descending sort options; each directory remembers its `orderBy`. Comic directories always sort by name.
- **Notification WebSocket** — the unread notification count is pushed over `/user-vault/open/api/v2/notification/ws`, gated on the login session and refused after authorization failure. Count changes are coalesced to at most one announcement per user per second.
- **Gallery watch** — a new drone page lists watched galleries and can trigger a watch task.
- **Thumbnails** — batch directory-thumbnail loading, oldest-file thumbnails for large directories, tooltips with a mobile toggle, and thumbnails for drone tasks.
- **Mobile/UI polish** — unified 768px breakpoint, compact drone-task and file-list layouts, CJK column fixes, and the new fape gallery page.

## Also in this release

- Manage files: Cmd/Ctrl+A adds the current page to the file tray; search reset navigates to the file's page; upload and new-directory panels hide when changing pages or entering directories.
- Drone tasks: edit the last page (button renamed to **Edit**); cancelled tasks can be updated; Update and Edit merged into one action; the previously selected directory is marked; remarks copy to the clipboard; task name and platform resolve asynchronously.
- Drone-created directories are marked comic.
- Preview: portrait images fit the viewport; a language change reloads the app.
- Thumbnail tooltips only on the preview column, with a toggle on mobile.

## Upgrade

Release manifest: [`db-changes.md`](./db-changes.md) → `v0.0.5`.

### 1. Apply the vfm DDL (required, before deploying vfm)

```sh
source docs/schema/v0.0.5/vfm.sql
```

SQL file: [`docs/schema/v0.0.5/vfm.sql`](../docs/schema/v0.0.5/vfm.sql).

Adds:

- `vfm.file_info.is_comic`
- `vfm.file_info.seq_key` (binary collation, fractional-index key)
- indexes `idx_parent_thumbnail`, `idx_parent_name`, `idx_parent_seq_key`
- table `vfm.dir_resume_cursor`

The vfm code reads these columns and indexes; deploying vfm first breaks it. The SQL is **not idempotent** — run it once. No other service has DDL in this release.

### 2. Gatekeeper: allow the notification WebSocket

`backend/gatekeeper/conf.yml` and `conf-prod.yml` add:

```yaml
ws-access-filter:
  rules:
    - path-patterns:
        - "/user-vault/open/api/v2/notification/ws"
      token-query-key: "token"
```

Without it the WebSocket route is rejected.

### 3. nginx: proxy the WebSocket upgrade

`deploy/nginx.conf` adds a `location` for `/user-vault/open/api/v2/notification/ws` that proxies to `gatekeeper:7070` with `Upgrade`/`Connection` headers and a 86400s read timeout.

### 4. user-vault: optional coalescing window

`user-vault.notification-count-coalesce-window` defaults to `1s`. Only override it if the default is wrong for your deployment.

`deploy/docker-compose.yml` and `deploy/backend.env` are unchanged.

## Fixes

- HTTP Range requests for previewed video now return correct partial content.
- Preview no longer leaks lightbox instances and coalesces fast swipe navigation.
- Gallery/drone lists no longer fetch the first page twice, and the default page limit applies before the first fetch.
- Directory browse history no longer stores a stale last-viewed file.
- `seq_key` non-empty filtering uses `Ne` instead of an incorrect comparison.
- Cancelled drone tasks can be updated, and update/edit share one action.
- Mobile drone-task columns, file-list column spacing, and CJK columns no longer collapse or overflow.
- Removed a deprecated logbot startup call.

## Notes

- The legacy Redis cursor hash (`vfm:dir:lastpage:<userNo>`) is no longer written. It is read once for a comic directory whose position exists only there, then carried into the table.
- Backend framework: miso `v0.4.15-beta.2` for acct, logbot, mini-fstore, user-vault, vfm; gatekeeper tracks the `v0.4.16-0.20260718082143` pseudo-version.
